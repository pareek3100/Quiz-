# PDF MCQ Quiz Master — Android APK Project

Complete build-ready Android project with **Admin Login**, **PDF MCQ Parser**, **CBT Exam Mode (Timer & Negative Marking)**, **Live Scoreboard**, and **Native Android Screen Monitoring (`FLAG_SECURE` + App-Switch Detection)**.

## Default Login Credentials
- **Admin Username:** `admin`
- **Admin Password:** `admin123` (can be changed inside **Admin > Settings**)
- **Student Login:** Enter any Full Name & Roll Number.

## Method 1: Build APK Online (No Android Studio Required)
1. Create a new repository on [GitHub](https://github.com/new).
2. Upload all files from this ZIP to the repository.
3. Open the **Actions** tab -> click **Build Android APK** -> **Run workflow**.
4. After ~2 minutes, download **PDF-MCQ-Quiz-Master-APK** (`app-debug.apk`) and install it on your Android phone.

## Method 2: Build APK Locally in Android Studio
1. Extract this ZIP file.
2. Open Android Studio -> **Open** -> select the extracted folder.
3. Wait for Gradle Sync to finish.
4. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Locate the compiled APK at `app/build/outputs/apk/debug/app-debug.apk`.
